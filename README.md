# 和弦播放器

**核心定位：和弦转换练习器。** 选中一组和弦，播放器按设定速度循环播放，你跟着节拍在倒计时内完成换和弦——练的是换和弦的反应速度、准确度与肌肉记忆。BPM 调节、扫弦/节拍器、下一和弦预告等全部功能，都是围绕"练转换"这一个目标设计的辅助工具，不承担编曲、演奏或音乐制作功能。

纯 HTML/CSS/JS 单文件应用，无需安装、无需联网，双击即可运行。桌面与手机浏览器均适配。

## 功能

- **以"练转换"为中心**：多选和弦按歌曲走向排列，设置合适速度循环播放；每和弦最后 1 拍高亮提醒，逼你在倒计时内换好下一个和弦
- 22 个常用和弦，指法图从第 1 品画起，支持多选与重复选中（复现歌曲和弦走向）
- 休止占位 ⌀，练歌时对齐节奏；随机模式洗牌播放
- BPM 调节（20–200），每和弦 4 拍；扫弦节奏两种可选（四分全下 / 二分全下，全下扫），预览扫弦（真实吉他采样）可关，关闭后为节拍器声
- 下一和弦预告（可开关），切换前高亮提醒，练习提前反应
- 桌面端三栏布局；移动端设置收为弹层，播放中点击画面暂停
- 快捷键：空格 开始/暂停，回车 开始，Esc 退出

## 使用

直接双击 `播放器本体/index.html`，或拖入浏览器打开。

手机预览用自带脚本起本地服务（手机与本机连同一 WiFi）：

```bash
./serve.sh          # 默认 5173 端口
./serve.sh 8080     # 指定端口
```

启动后终端显示 Network 地址，手机浏览器打开即可。

## 配置与自定义

所有玩法配置（和弦库、扫弦节奏、节拍、主题配色）都集中在 `播放器本体/index.html` 顶部的「配置区」，改完保存刷新即生效。

功能设计细节、每个配置项的作用与修改方法，见 **[配置与设计说明](配置与设计说明.md)**。

快速示例——增加一个自定义和弦：

```js
{ name:'Cadd9', frets:[-1, 3, 2, 0, 3, 0], fingers:[0, 3, 2, 0, 4, 0] }
```

- `frets`：六弦品格（低 E → 高 e），`-1` 闷音（X），`0` 空弦
- `fingers`：按弦手指 1–4，`0` 不按
- `barre`：可选横按配置 `{ fret, from, to }`
