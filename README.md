# 和弦播放器（Chord Player）

一个纯 HTML/CSS/JS **单文件**实现的吉他和弦转换练习器：无需安装、无需联网，双击即可运行。

## 功能特性

- 左中右三栏布局：和弦选择 · 练习主区域 · 设置面板
- 内置 20 个常用和弦（大小三和弦、属七、大七、小七），指法图统一从第 1 品画起
- 支持多选和弦，按选中顺序循环播放；取消选中后，后续序号自动递补
- 随机模式：洗牌播放，一轮内不重复
- BPM 速度调节（20–200，步进 5），每和弦停留 2 拍（半小节）
- 预览扫弦：Web Audio 实时合成吉它扫弦声（顺序扫弦，无需任何音频文件）
- 切换动画：25% 淡入 / 50% 保持 / 25% 淡出，时长随 BPM 自动缩放
- 键盘控制：空格 开始 / 停止，回车 开始，Esc 退出

## 使用

直接双击 `播放器本体/index.html`，或拖入任意浏览器打开。

### 操作步骤

1. 在左侧点击选择一个或多个和弦（列表可滚动）
2. 在右侧调整速度（BPM）、预览和弦、随机开关
3. 按空格或回车开始练习，再按空格停止

### 快捷键

| 按键 | 行为 |
| --- | --- |
| 空格 | 开始 / 停止练习 |
| 回车 | 未开始时开始练习 |
| Esc | 播放中退出到未开始状态 |

## 自定义和弦

打开 `播放器本体/index.html`，在文件顶部的 `CHORDS` 数组中增删和弦（代码中有注释说明）：

``` js
{ name:'C', frets:[-1, 3, 2, 0, 1, 0], fingers:[0, 3, 2, 0, 1, 0] }
```

- `frets`：低 E → 高 e 六根弦对应的品格，`-1` 为闷音（X），`0` 为空弦
- `fingers`：每根弦的按弦手指（1–4），`0` 表示不按
- `barre`：可选，横按配置 `{ fret, from, to }`（如 F 和弦）

扫弦节奏型在 `STRUM_PATTERN` 常量中修改，例如改为 `['down', 'up']`（下-上）。

## 技术说明

- 单文件 `index.html`，原生 HTML / CSS / JS，无任何外部依赖，可离线使用
- 和弦指法图由内联 SVG 动态绘制
- 扫弦声音由 Web Audio API 实时合成，不依赖音频素材
- 状态管理采用普通 JS 对象 + 重渲染
