# 和弦播放器

纯 HTML/CSS/JS 单文件吉他和弦转换练习器，无需安装、无需联网，双击即可运行。桌面与手机浏览器均适配。

## 功能

- 20 个常用和弦，指法图从第 1 品画起，支持多选与重复选中（复现歌曲和弦走向）
- 休止占位 ⌀，练歌时对齐节奏；随机模式洗牌播放
- BPM 调节（20–200），每和弦 2 拍；预览扫弦（真实吉他采样）可关，关闭后为节拍器声
- 下一和弦预告（可开关），切换前高亮提醒，练习提前反应
- 桌面端三栏布局；移动端设置收为弹层，播放中点击画面暂停
- 快捷键：空格 开始/暂停，回车 开始，Esc 退出

## 使用

直接双击 `播放器本体/index.html`，或拖入浏览器打开。

手机预览用自带脚本起本地服务（手机与本机连同一 WiFi）：

```bash
./serve.sh          # 默认 5173 端口
./serve.sh 8080     # 指定端口
```

启动后终端显示 Network 地址，手机浏览器打开即可。

## 自定义和弦

编辑 `播放器本体/index.html` 顶部的 `CHORDS` 数组：

```js
{ name:'C', frets:[-1, 3, 2, 0, 1, 0], fingers:[0, 3, 2, 0, 1, 0] }
```

- `frets`：六弦品格，`-1` 闷音（X），`0` 空弦
- `fingers`：按弦手指 1–4，`0` 不按
- `barre`：可选横按配置 `{ fret, from, to }`

扫弦节奏在 `STRUM_PATTERN` 常量中修改。
